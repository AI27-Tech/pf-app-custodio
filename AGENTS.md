## Commands (run from repo root via el wrapper)

- Build debug APK: `./gradlew assembleDebug`
- Build release APK (firmado): `./gradlew assembleRelease`
- Unit tests (JUnit4, no device needed): `./gradlew testDebugUnitTest`
  - Single test: `./gradlew testDebugUnitTest --tests "com.ai27.app.custodio.ExampleUnitTest"`
- Instrumented / Compose UI tests (need emulator or connected device): `./gradlew connectedDebugAndroidTest`
- Install on device: `./gradlew installDebug`
- Reglas de seguridad contra el Emulator Suite (requiere Node): `cd firebase && npm test`. Ejecuta `firebase emulators:exec --only firestore,storage --project demo-custodio` sobre `firebase/test/reglas.test.js`. Primera vez: `cd firebase && npm install` (la carpeta `firebase/node_modules/` está gitignored).

## Toolchain

- AGP 9.4.1, Gradle 9.6.0 (wrapper), Kotlin 2.3.10 (compose compiler plugin) + KSP 2.3.10, Compose BOM 2026.02.01.
- AGP 9 usa Kotlin embebido (built-in): no se aplica `org.jetbrains.kotlin.android`. El plugin de compose y KSP deben versionarse a la par del Kotlin embebido de AGP (2.3.10). Hilt 2.60.1 (requiere ≥2.59 para AGP 9), google-services 4.5.0 aplicado en `:app`.
- JVM toolchain 25 auto-resolved via foojay (`gradle/gradle-daemon-jvm.properties`); Java source/target 11.
- minSdk 26, target/compileSdk 37, applicationId `com.ai27.app.custodio`.

## AGP 9 gotchas (most online examples use the removed old DSL)

- `compileSdk` must use the new block form: `compileSdk { version = release(37) }`. A bare `compileSdk = 37` will not compile.
- Minify/R8 lives in `buildTypes.release.optimization { enable = ... }`. `minifyEnabled` / `isMinifyEnabled` no longer exist. Release currently has R8 disabled (`optimization { enable = false }`).
- Keep rules live in `app/src/main/keepRules/` (existing `rules.keep`), not `proguard-rules.pro`.
- El plugin de Crashlytics (`com.google.firebase.crashlytics`) está versionado en el catálogo y **aplicado en `:app`** desde B7, con el SDK inicializado en `AppCustodioApplication` y recolección explícita en el manifest. `mappingFileUploadEnabled`/el bloque `firebaseCrashlytics { }` NO se usan: el accessor no genera con AGP 9 y con R8 apagado no hay mapping; el reporte real queda activo cuando exista la consola (carril A).
- La firma de release lee `keystore.properties` (gitignored) con `storeFile`/`storePassword`/`keyAlias`/`keyPassword`; si el archivo no existe, `release` queda sin firmar. El keystore vive en `app/keystore/release.jks` (gitignored por `*.jks`) y hay que resguardarlo fuera del repo: es lo único que permite actualizar instalaciones ya desplegadas.

## Nota: quirk del Emulator Suite (Firestore)

- Con la plantilla 13.29.0 del Firebase CLI, el emulador de Firestore evalúa las reglas de lectura de `list`/`runQuery` muestreando documentos que llegan **sin `custodioUid`**, y responde 403 `Property custodioUid is undefined on object. for 'list'` aunque el documento real tenga el campo. Verificado con el emulador corriendo como proyecto `custodio-906e7268`.
- No afecta a la app: el pipeline solo usa `get` por llave, `set`/`update` y el `get()` cruzado de las reglas de Storage; el historial lee de Room y nunca lista Firestore. Para validar contra el emulador, consulta por llave (REST `GET .../documents/reportes/{id}`) en lugar de `list`. `npm test` (rules-unit-testing) usa su propio motor in-process y no se ve afectado.
